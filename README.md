FolderSync2WPS  文件夹同步器 · 使用说明
========================================

【重要 · 先读这一段】
  1. 请把 zip 里的「FolderSync2WPS-源码」整个文件夹解压出来再用，
     不要只把 .bat 单独拖到桌面 —— 它要找同目录的 .ps1 和源码。
  2. 双击「一键生成应用包.bat」不会再出现乱码 / 「不是内部或外部命令」。
     如果还看到那种报错，说明你打开的是旧版压缩包，请重新解压本次的 zip。
  3. 生成 exe 需要本机装了 Python 3.10+（原来 build.ps1 里的 Python313
     路径说明你机器上应该有）。实在不想装，用「云端生成exe.bat」。
  4. 若双击 exe 弹出 "bad argument 0: must be name of window"：
     这是旧包的启动崩溃，请用最新源码包覆盖后重新运行
     「一键生成应用包.bat」重打一次。已有的 config.json /
     state.db / browser_profile 不会被覆盖。
  5. 若界面能打开、但点「添加配置」等按钮没反应：这是旧美化包的事件绑定
     覆盖问题，请用最新源码包覆盖后重新运行「一键生成应用包.bat」重打一次。

【表格 → 企业微信：新增两个设置（都在第 ④ / ⑤ 张卡）】
  · 发送条件可选「只有变成指定文字才发」：填目标文字（多个用 | 分隔）、
    选「完全一致 / 包含」、可勾「忽略大小写和空格」。只有当触发列/行
    从别的值变成这个文字时才发，其他列/行一律不影响。
  · 每条信息下面有「前加 / 后加」：在格式转换之后追加纯文本，
    原来的日期、小数、去空格转换照常生效。
  · 配置好后点「保存」不会再消失；退出、收托盘、切页签也都会自动保存。

【外观与动效】
  · 已按微信桌面端的浅灰白 + 轻圆角重做，滚动 / 切页 / 提示条都带
    130–180ms 的统一缓动，动画期间照常点击，不会卡顿。
  · 远程桌面、虚拟机或低配机若想关掉动画，新建系统环境变量
    FOLDERSYNC_REDUCED_MOTION = 1 后重启程序即可（功能完全不变）。

【怎么启动】
双击本文件夹里的 FolderSync2WPS.exe。
第一次启动会在这里自动生成 state.db 和 browser_profile 文件夹，
这两个是数据，不要删、不要移到别处。

【四个绝对不能删的东西】
  config.json        你的全部配置
  state.db           去重记录、写入记录、已发送行指纹
  browser_profile    WPS / 金山文档的登录态（重新登录后可重建）
  runtime.log        无界面模式下的兜底日志（有错才出现）

【功能一：文件夹 → 表格】
  1. 左侧点「＋ 添加配置」，选一个要盯的文件夹
  2. 填命名分隔符（如 A-B-C-D 用「-」），在「同步目标」里设表格和
     「每段信息写到哪一列」
  3. 点右上「开始监听」。之后在这个目录里新建文件夹，就会自动写进表格

  在线表格：需要本机装有 Microsoft Edge。第一次用点侧栏「重新登录」，
  在弹出的浏览器里扫码登录 WPS，登录态会存在 browser_profile 里。
  本地表格：指向 WPS 同步文件夹里的 .xlsx；写入瞬间请先不要在
  WPS/Excel 里打开这个文件（程序用原子替换写盘，被占用会明确报错，
  不会写坏原表）。

  顶部「追加方式」两种口径：
    ① 按整张表任意列/行判断末尾
    ② 只看要填的那几列/行，别的列再长也不管

【功能二：表格 → 企业微信】
  点顶部「② 表格 → 企业微信」切过去 →「＋ 新建提取配置」
    · 选来源：本地 .xlsx 或 WPS 在线表格链接 + 工作表名
    · 点「读取表结构」自动列出表头，加字段后用 ↑↓ 调发送顺序
    · 选识别范围口径（只看选定列/行 或 按整张表）
    · 填企业微信群机器人 Webhook、每天时间、消息模板
    · 先点「试运行」确认落位（只读、不写、不发送），再「保存」
    · 点「立即扫描并发送」马上发一次；或点「开始运行」交给每日定时

  已发过的行按「行指纹」记住，不会被每日汇总反复重发。
  想重新发一遍：工作区二 →「清空已发送记录」。

  【只在指定列 / 行新增时才发】（可选，第 ④ 张卡）
    勾「启用触发监控」，填一个触发列（向下，如 C）或触发行（向右，如 2）。
    之后程序只盯这一列 / 行：它没输入新数据就一条都不发；它一有新值，
    就只发这些新行 / 列的信息。其他列再长、别的行被修改统统不触发，
    连「当天没有记录也发一条」也让位。
    第一次启用会先把当前数据记成基线、不补发历史；之后只发新增。
    开启后约每 30 秒检查一次，不受「每天时间」限制；触发列/行即使不在
    「提取字段」里，也会自动补到消息末尾，保证新增的数据一定发得出去。
    也可以一个字段都不选，只填触发列/行就能用。
    试运行结果里会写明本次新增几处；「立即扫描并发送」首次会提示已建基线。
    点「清空已发送记录」会同时清掉触发基线（之后按首次启用重建基线）。
    触发列大小写都认（填 c 和 C 一样）；配置名里带 % 或下划线也不会串台。

【常用快捷键】
  F5   立即同步现有文件夹      F6  试运行（只看落点）
  F2   编辑当前配置            Ctrl+S  保存
  Ctrl+L  展开 / 收起运行日志

【开机自启 / 托盘】
  主界面「运行状态」里打开「开机自动启动」，登录后自动缩到托盘监听。
  点侧栏「隐藏到托盘」收起窗口；关闭窗口也是收起，不会退出。
  真正退出：右下角托盘图标 → 右键 → 退出。

【出问题先看哪儿】
  按 Ctrl+L 展开运行日志，可按关键字搜、按级别筛、一键复制。
  写入失败会自动按 10 秒 / 30 秒 / 90 秒重试，重试队列数量显示在
  「运行状态」右下角。

【卸载】
  先在主界面关掉「开机自动启动」，退出托盘程序，然后整个删掉
  本文件夹即可。想保留配置就先备份 config.json 和 state.db。

【从源码重新生成这个应用包】
  见源码目录里的「一键生成应用包.bat」（需要 Python 3.10+）。

【新增：偏好设置（左侧 工具 → 偏好设置）】
  · 外观：强调色（蓝/绿/灰/橙）、界面密度（紧凑/标准/宽松）、
    动效开关。强调色和密度下次启动生效，动效保存后立即生效。
  · 运行：触发监控多久看一次表（默认 30 秒）、启动后进哪个
    功能页、日志保留多少天、开机自启、重复时是否先问。
  · 数据：备份数据（配置+去重记录打包 zip）、从备份恢复、
    打开配置目录、清空运行记录。恢复前会把现有文件留成 .bak。
  · 页面底部还有快捷键速查。

【这些坑已经填上】
  · 两套配置起同一个名字：保存时会拦住并说明「去重记录会混」。
  · 在功能二编辑过的配置，不会再偷偷变成「已启用」。
  · Webhook 不像企业微信机器人地址、发送时间写成 25:99：
    输入时就变橙字提示，存之前再确认一次。
  · 字段写成 A1（向下）或 A（向右）：那一行当场提示怎么改。
  · 功能二改完没点保存：配置行右侧会出现「● 有未保存修改」；
    切页或退出会自动帮你写回。
  · 消息模板新增 4 个常用格式，点一下就填好，还能继续改。
  · 试运行结果可以点「复制结果」直接拷走。

【更顺手】
  · 点侧栏配置不再整排重建，切换更快、不闪。
  · 低配或远程桌面：偏好设置里关掉「界面动效」即可。

【新功能：快捷搜索 Ctrl+K】

    · 输入「主题」「日志」「体检」或者配置名，都能搜到。
    · 最上面那一条是绿色的，表示按回车就执行它。
